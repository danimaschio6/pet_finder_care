🐾 Pet Finder & Care
🌟 Plataforma integral para reencuentro, adopción y cuidado de mascotas.
Pet Finder & Care es una aplicación móvil desarrollada para crear una comunidad de apoyo, con el objetivo principal de conectar mascotas perdidas con sus dueños, facilitar procesos de adopción y proporcionar herramientas esenciales para el cuidado y gestión del bienestar animal.

Actualmente, el proyecto se encuentra en la fase de desarrollo del Prototipo UI/UX con datos estáticos, enfocándose en un diseño limpio, intuitivo y adaptativo.

🛠️ Tecnologías Utilizadas
Este proyecto está construido como una aplicación móvil (cross-platform) utilizando:

✨ Características Principales (Fase de Prototipo)
Las siguientes pantallas y módulos componen el prototipo actual:

Página de Inicio (Home): Dashboard con feed de mascotas y avisos cercanos.

Reportar Mascota: Formulario para crear avisos de mascotas perdidas o encontradas.

Listado/Búsqueda: Vista de mascotas disponibles para reencuentro.

Perfil de Mascota: Gestión de información, recordatorios de salud e historial.

Sistema de Chat (Simulado): Interfaz de conversación para la comunicación entre usuarios (se utiliza la patita de gato 🐾 como icono de envío).

Autenticación (Pendiente): Pantallas de Login y Registro diseñadas.(Esta de forma estática, sin backend).

🚀 Instalación y Ejecución Local
Para ejecutar este proyecto en tu entorno local, sigue los siguientes pasos. Necesitarás tener Node.js y Expo CLI instalados globalmente.

1. Clonar el Repositorio
Bash

git clone <URL_DE_TU_REPOSITORIO>
cd pet-finder-care
2. Instalar Dependencias
Usa Yarn o npm para instalar las dependencias del proyecto:

Bash

# Con Yarn
yarn install

# O con npm
npm install
3. Ejecutar la Aplicación
Inicia el servidor de desarrollo de Expo:

Bash

npx expo start
Esto abrirá una página web en tu navegador. Desde allí, puedes:

Escanear el código QR con la aplicación Expo Go en tu dispositivo móvil (iOS o Android).

Presionar w para abrir la aplicación en un navegador web.
